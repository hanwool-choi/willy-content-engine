### 0-1. 즐겨찾기 수집이 막힌 상태

`tools/pulluk_favorites.py` 실행이 이 환경에서 실패한다. 네트워크 정책이 `naver.me`를
차단(egress 403)해서 공유 폴더에 접근할 수 없다. 도구 자체의 문제는 아니고, 로컬 PC에서는 정상 동작할 것.

따라서 **아래 장소들은 전부 "후보"이며, 확정 전에 반드시 대조해야 한다.**

```bash
python tools/pulluk_favorites.py --addr 파주
python tools/pulluk_favorites.py --addr 강화
# 좌표 반경으로 더 넓게 훑을 때 (근교는 --addr 매칭이 얇을 수 있음)
python tools/pulluk_favorites.py --center 37.71,126.70 --radius 8    # 파주 헤이리 일대
python tools/pulluk_favorites.py --center 37.74,126.48 --radius 10   # 강화읍 일대
```

**예상 리스크**: 스팟 폴더 189곳이 쇼핑 편중(§11.2)이라, 근교 지역은 등록 자체가 얇을 가능성이 높다.
즐겨찾기에 3곳 미만만 잡히면 두 가지 중 선택 —
(a) 해당 지역을 답사 후 즐겨찾기에 먼저 채워 넣고 다음 주로 미룬다,
(b) 서울 근교 대신 즐겨찾기 밀도가 확인된 지역(강남·성수 등)의 "실내 완결" 코스로 시리즈를 시작한다.
채널 신뢰 기반이 "큐레이터가 실제 저장해둔 곳"이므로, 밀도가 안 나오면 (a)가 원칙에 맞다.

## 1. 시리즈 컨셉

### 왜 지금 '실내'인가
8월 폭염기. 근교 드라이브 콘텐츠는 널렸지만 전부 야외(계곡·바다·전망 카페) 기준이라
**"차는 끌고 나가고 싶은데 밖에 서 있긴 싫다"**는 수요가 비어 있다.
가을·장마철에도 후킹만 바꿔서 재사용 가능한 시리즈 골격(폭염 → 우천 → 한파).

### 왜 '드라이브'인가
차가 있어야만 성립하는 코스여야 콘텐츠에 존재 이유가 생긴다.
대중교통으로 똑같이 갈 수 있으면 그냥 나들이 코스지 드라이브 코스가 아니다.
→ **선정 기준: 서울 기준 편도 50~90분 + 대중교통 환승 2회 이상 or 1.5배 이상 소요.**

### 2지역 선정과 대비 구도

| | **파주 편** | **강화 편** |
|---|---|---|
| 성격 | 도시형 근교 / 문화·쇼핑 실내 | 섬 / 폐공장·역사 레트로 실내 |
| 드라이브 명분 | 자유로 주행 자체가 코스의 일부 | 초지대교 입도, 대중교통 최악 |
| 실내 앵커 | 미술관·대형서점·아울렛 (냉방 확실, 체류 무제한) | 폐공장 개조 대형카페·실내시장 |
| 우천 대응 | 실내 밀도 높아 완전 대응 | 이동 구간 노출 있음 → 우산 필요 |
| 타깃 | 커플·친구, 무난한 첫 코스 | 사진 찍는 친구 조합, 취향 강한 사람 |
| 난이도 | 낮음 (시리즈 1편으로 적합) | 중간 (2편에서 톤 확장) |

파주를 1편에 두는 이유: 실패 확률이 낮고, "실내 코스" 컨셉이 한 번에 이해된다.
강화는 같은 컨셉의 변주라 2편에서 "이 채널은 무난한 데만 가는 게 아니다"를 증명하는 역할.

**대안 2순위**(위 두 곳의 즐겨찾기 밀도가 안 나올 경우): 용인(호암미술관·백남준아트센터 축) → 양평(구하우스미술관 축).
용인이 실내 밀도가 더 높고, 양평은 §4에 이미 「브리핑 No.014 양평 드라이브」로 예시가 잡혀 있어 중복 우려.

## 2. 파주 편 — 「자유로 타고 가서 하루 종일 에어컨 밑」

### 2-1. 동선 설계 (슬롯 구조)

한 방향: **서울 → 자유로 북상 → 출판도시 → 헤이리 → 프로방스/아울렛 → 자유로 남하 귀가.**
되돌아오는 구간 없음. 총 이동 40분 내외(지역 내), 나머지는 전부 실내 체류.

| # | 슬롯 역할 | 조건 | 체류 | 다음 구간 이동 |
|---|---|---|---|---|
| 1 | 점심 | 출판도시/헤이리 초입. 주차 확보, 웨이팅 30분 이내 | 70분 | 차 10분 |
| 2 | 실내 문화 앵커 | 미술관 or 대형 서점. 냉방·체류시간 제한 없음 | 90분 | 차 10분 |
| 3 | 대형 카페 | 층고·좌석 여유. 앉아서 쉬는 구간 = 코스의 에어컨 휴게소 | 60분 | 차 10분 |
| 4 | 실내 쇼핑 | 아울렛/편집숍. 비 와도 무관, 자유시간 배치 | 90분 | 차 5분 |
| 5 | 저녁 (분기) | A안 고기·정찬 / B안 가볍게 → 노을 시간 맞춰 귀가 | 80분 | 자유로 남하 |

**후보 장소** (전부 즐겨찾기 대조 필요 — 확정 아님):
2번 슬롯은 미메시스아트뮤지엄 / 지혜의숲 계열, 4번은 파주 아울렛 축이 기본선.
1·3·5번은 즐겨찾기 카페·식당 폴더에서 파주 필터 결과를 보고 채우는 게 맞다.

### 2-2. 본문 초안 (§11.3 템플릿)

```
목적지 정해지면 코스부터 짜는 파워J가
밖에 1분도 서 있기 싫은 8월 주말, 파주 실내 코스 딱 짜드림.
(광고 협찬 절대 아님)

1. 자유로 타고 올라가서 '○○○'에서 점심.
   12시 전에 도착해야 안 기다린다. 주차 넉넉함.
2. '○○○' 실내 관람.
   여기가 이 코스의 본체다. 에어컨 세고 오래 앉아 있어도 눈치 안 준다.
   자유시간 90분.
3. '○○○'에서 커피.
   층고 높은 데라 사람 많아도 안 답답함. 2층 창가 자리 노려라.
4. '○○○'에서 쇼핑.
   여기부터 저녁까지 실내로만 이어진다. 비 와도 우산 안 씀.
5. '○○○'에서 저녁 or '○○○' 가볍게 하고 노을 시간 맞춰 자유로 복귀.

하루 종일 밖에 서 있는 시간 총 10분.
앞으로 짜줄 코스가 무궁무진 너무 많다.
(+) 팔로우 해두면 이제 주말에 뭐할지 고민할일 없음.
```

- 후킹 대안(재사용): 폭염 → `"땡볕에 주차장부터 지치는 8월"`, 우천 → `"비 예보 뜬 주말"`, 한파 → `"밖에 나가면 손 시린 날"`
- 킬러 문장: **"하루 종일 밖에 서 있는 시간 총 10분"** — 실내 코스 시리즈의 고정 마무리 지표로 쓸 수 있다. 지역마다 숫자만 바꾸면 됨

### 2-3. 답글 구성

- **답글1** 📍 5곳 주소 + 네이버지도 링크 + 주차 정보(무료/유료·대수) + 지역 내 총 이동 40분
- **답글2** 다음 투어지 접수. "차 있는데 갈 데 없는 지역 있으면 댓글로. 다음 실내 코스 거기로 짬"

## 3. 강화 편 — 「섬까지 갔는데 하루 종일 실내」

### 3-1. 동선 설계 (슬롯 구조)

한 방향: **서울 → 김포 → 초지대교 입도 → 강화읍 → 서쪽 해안 → 강화대교로 귀가.**
들어온 다리와 나가는 다리를 다르게 써서 되돌아가는 구간을 없앤다. 이게 이 코스의 설계 포인트.

| # | 슬롯 역할 | 조건 | 체류 | 다음 구간 이동 |
|---|---|---|---|---|
| 1 | 점심 | 초지대교 건너 바로. 입도 직후 배 채우고 시작 | 70분 | 차 15분 |
| 2 | 대형 실내 카페 (메인) | 폐공장·창고 개조급 규모. 사진 구간 = 코스의 하이라이트 | 90분 | 차 10분 |
| 3 | 실내 시장/상점가 | 비·더위 무관. 군것질 자유시간 | 50분 | 차 10분 |
| 4 | 실내 전시·역사 앵커 | 강화읍 권역. 실내 위주 동선 확인 필수 | 60분 | 차 25분 |
| 5 | 저녁 (분기) | A안 해안 쪽 정찬 / B안 읍내 간단 → 강화대교로 귀가 | 80분 | 서울 60분 |

**후보 장소** (즐겨찾기 대조 필요): 2번은 조양방직 계열 폐공장 카페가 기본선, 3번은 강화풍물시장.
1·4·5번은 즐겨찾기 필터 결과에서 채운다.

### 3-2. 본문 초안 (§11.3 템플릿)

```
목적지 정해지면 코스부터 짜는 파워J가
차 있으면 한 시간, 근데 하루 종일 실내인 강화 코스 딱 짜드림.
(광고 협찬 절대 아님)

1. 초지대교 건너자마자 '○○○'에서 점심.
   섬 들어와서 배부터 채우는 게 맞다.
2. '○○○'.
   방직공장 개조한 데라 규모가 말이 안 된다. 여기서 사진 다 찍힌다.
   자리는 안쪽 들어가서 잡아라, 입구 쪽은 사람 계속 지나감.
3. '○○○' 실내 시장에서 군것질.
   지붕 있어서 비 와도 상관없음. 자유시간 50분.
4. '○○○' 둘러보기.
   강화 온 티는 내야 하니까. 실내 위주로만 돈다.
5. '○○○'에서 저녁 먹고, 들어온 초지대교 말고 강화대교로 나오면
   왔던 길 안 겹치고 서해 노을 보면서 복귀됨.

섬 하루 코스인데 밖에 서 있는 시간 15분.
앞으로 짜줄 코스가 무궁무진 너무 많다.
(+) 팔로우 해두면 이제 주말에 뭐할지 고민할일 없음.
```

- 이 편의 차별점은 **"다른 다리로 나온다"** 한 줄. 지도 보고 짜본 사람만 아는 정보 = 답사 신뢰도 증명
- 강화는 이동 구간에 야외 노출이 있으므로 "완전 실내"라고 쓰지 말 것. 15분이라고 정직하게 숫자 박는 쪽이 신뢰에 낫다

### 3-3. 답글 구성

- **답글1** 📍 주소·지도링크·주차 + **입도/출도 다리 안내**(초지대교 IN / 강화대교 OUT) + 주말 정체 시간대
- **답글2** 투어지 접수. "섬 코스 더 필요하면 댓글. 영종·대부도도 짤 수 있음"

## 4. 사전답사 체크리스트 — 실내 코스 추가 항목

§5의 8항목에 더해, 실내 코스는 아래 4개를 추가로 통과해야 한다. 컨셉이 "실내"인데
정작 실내 조건이 안 맞으면 코스 전체가 무너진다.

- [ ] **냉난방·실내 규모** — 대형 카페가 실제로 시원한지(유리 온실형은 8월에 더 더움), 좌석 간격
- [ ] **체류시간 제한** — 카페 이용시간 제한(1시간 30분 등) 유무. 90분 슬롯 배치와 충돌하는지
- [ ] **주차장 → 입구 노출 거리** — 우천 시 우산 필요 여부. 코스 총 "야외 노출 분"의 근거가 됨
- [ ] **실내 비중** — 전시·역사 앵커가 실제로 실내 위주인지(야외 유적 중심이면 실내 코스에 못 넣음)

마지막 항목이 각 편의 킬러 문장("밖에 서 있는 시간 총 N분") 숫자의 근거다. 답사 때 실측할 것.
