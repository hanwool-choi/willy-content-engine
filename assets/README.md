# assets

게시 페이지가 함께 내보내는 정적 파일.

## og.png — 링크 공유 미리보기 이미지

카카오톡·슬랙·X 등에 보드 주소를 붙여넣을 때 뜨는 썸네일이다.

- 파일명은 **`og.png`로 고정** (`build_site.py`가 이 이름을 찾는다)
- 권장 크기 **1200 × 630** (1.91:1). 최소 600 × 315
- 이 파일이 없으면 `og:image` 태그 자체를 넣지 않는다 — 없는 이미지를
  가리키면 미리보기가 깨진 채로 뜨기 때문이다

교체하려면 같은 이름으로 덮어쓰고 커밋하면 된다. 다음 게시부터 반영된다.
캐시 때문에 바로 안 바뀌면 카카오톡·페이스북의 디버거에서 새로고침을
요청하면 된다.
